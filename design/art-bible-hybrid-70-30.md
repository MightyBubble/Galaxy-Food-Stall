# Galaxy Food Stall 美术指南：偏执平装本 × 迷幻海报（70 / 30）

## 1. 概述

本指南把项目现有两套视觉方向收成一条可执行主风格：

- **70%《偏执科幻平装本》**：画面气质、构图、叙事怪异、纸本印刷质感、现实裂痕。
- **30%《70 年代迷幻海报》**：局部高饱和色、液体轨道线、可食用的有机轮廓、少量放射能量。

一句话定调：

> 玩家打开的不是热闹太空嘉年华，而是一本落满烟渍的失落科幻小说封面——封面里的宇宙碰巧是用食物搭成的，而且有人在盯着它。

游戏世界观落点：`Galaxy Food Stall` 是一座「每颗星球都可食用、又可疑得不像话」的星系。美食是地貌，不是表情包；宇宙是证据，不是派对。

本指南是后续星球、怪物、美食、UI 概念的单一事实来源（SSOT）。生成图、定稿概念、界面试做都必须先对齐这里的混比，而不是各自回退到纯海报或纯 CRT。

## 2. 结构

| 层级 | 负责什么 | 70/30 落点 |
|---|---|---|
| A. 气质层 | 玩家第一眼的情绪 | 70：冷、静、被观察；30：偶发的色温脉冲 |
| B. 构图层 | 信息与视觉重心 | 70：封面式负空间 + 单一不可能主体；30：液体轨道/放射丝带作辅线 |
| C. 材质层 | 印刷感与时代感 | 70：平装纸、气刷、网点、错版；30：丝网叠印色块、过印缝 |
| D. 符号层 | 世界观可读符号 | 70：监视镜头、刻度、假地平线、家常器物；30：酱汁轨道、熔边轮廓 |
| E. 对象层 | 星球 / 怪物 / 美食 / UI | 见第 3 节概念库 |
| F. 验收层 | 玩家视角 UAT | 见第 6 节 |

### 2.1 混比口诀（创作时默念）

1. 先摆一个「平装本封面式」静物：空、冷、怪、有人在看。
2. 再给主体加「迷幻海报」的一点热：一两道液体轨道、一处酸黄/鳄梨绿高光、一条熔边丝带。
3. 如果画面开始像音乐会海报或彩虹曼陀罗，把海报感削掉，直到偏执感回来。
4. 如果画面变成终端小窗或霓虹 HUD，整张作废。

### 2.2 主色板（混合后）

底色场永远偏平装本；海报色只作局部点火。

| 角色 | 色名 | 用途 | 占比建议 |
|---|---|---|---|
| 纸底 | 尼古丁奶油 `#E8D9C0` | 大面积背景、纸边 | 主底 |
| 虚空 | 褐黑 `#1C1712` | 宇宙空洞、深影 | 主底 |
| 官僚青 | 褪色青绿 `#5E7A78` | 器械、刻度、冷空气 | 次底 |
| 氧化橙 | `#C86A3C` | 重点热源、酱海、警戒 | 海报点火 |
| 酸黄 | `#E2B84B` | 小面积高光、放射芯 | 海报点火 |
| 鳄梨绿 | `#6F8B3E` | 菜叶大陆、有机轮廓 | 海报点火 |
| 闷红 | `#8B3A2F` | 深酱、血感、熟成 | 平装本阴影色 |
| 尘黄 | `#B9A06A` | 中调、陈纸、干酪尘 | 过渡 |

规则：一张图同时点火的海报强调色不超过 3 种；主色场必须仍能读出「旧书封面」。

### 2.3 印刷工艺（必须可见）

- 平装纸齿、褐边、哑光气刷。
- 细网点阴影，不是现代柔光。
- 轻微错版叠印（色边漂一点）。
- 允许丝网过印缝，但不做全幅彩虹渐变。
- 禁止：光滑 3D、真实食物摄影、现代概念画抛光、赛博霓虹。

## 3. 详情

### 3.1 风格合同：什么必须像，什么绝不能像

#### 必须像

- 一本 1970 年代实验性科幻平装书封面，被人从阁楼翻出来。
- 食物同时是星球：看一眼认出菜，再一眼承认它是天体。
- 至少有一处「现实不稳」：尺度打架、重复月亮、假地平线、监视几何、家常器物漂在虚空。
- 幽默是冷的：不是卖萌，是「宇宙把午餐当证物」。

#### 绝不能像

- 纯迷幻音乐会海报、扎染模糊、儿童绘本可爱球。
- 现代太空射击 HUD、CRT 终端小窗、霓虹仪表盘。
- 直接复刻任何真实小说封面、书名、作者、出版社。
- 美食变成贴纸拼贴或商品货架特写。

### 3.2 星球概念（Food Planets）

原则：用地貌讲菜，不靠标签；用地貌讲异常，不靠表情。

每个星球写四件事：**认菜点 / 行星地貌 / 偏执装置 / 海报点火**。

#### 名册落地（基于现有十星）

| 星球 | 认菜点 | 行星地貌 | 偏执装置（70） | 海报点火（30） |
|---|---|---|---|---|
| 牛肉丸星 | 多孔肉糜球、酱顶 | 火山是挤出的肉糜丘，熔岩是番茄酱 | 桌面盐瓶与行星同框，刻度尺量直径 | 酱汁形成一条液体轨道环 |
| 生煎包星 | 褶皱顶、芝麻、焦底 | 褶皱是山脉，芝麻是陨石点，焦底是暗面 | 切开截面漂在旁，像被归档的样本 | 蒸汽带变成柔波丝带，不喷成卡通云 |
| 意面星 | 缠绕长面、酱斑 | 大陆是面条束，环是帕玛森尘环 | 叉子以官僚角度插入，像取样探针 | 面条束边缘少量熔边波浪 |
| 芝士星 | 孔洞、凝脂黄 | 孔是撞击坑，拉丝是磁层丝 | 复制月影错位，两轮孔洞对不上 | 酸黄高光只打在迎光孔缘 |
| 豆腐星 | 方块阵列、凝白 | 立方体城市/矿脉，切面网格 | 方块像被分类归档的货柜 | 鳄梨绿葱花仅作点状大陆 |
| 皮蛋星 | 松花纹、琥珀胶、墨心 | 外层半透明胶质大气，核是暗绿心 | 剖面图示漂在侧，像病理切片 | 胶质外圈允许深紫罗兰薄晕 |
| 炸薯球星 | 金壳裂纹、内绵 | 壳是沙漠硬壳，裂纹是峡谷 | 油光被画成可疑反光，像人造涂层 | 氧化橙焦斑作局部日珥 |
| 卷心菜星 | 叶脉、层层叠 | 叶脉即大陆脊，层叠即地层 | 叶片像被翻开的文件页 | 叶绿用鳄梨绿，忌荧光 |
| 醋冻星 | 半透明凝胶、酸色 | 透光月体，内部悬浮碎屑 | 凝胶里嵌着不明标签块（不可读） | 内部碎屑用少量酸黄闪点 |
| 番茄酱星 | 厚亮红海、油膜 | 永久红风暴洋，气泡即岛 | 被镜头/天线对准的「重点观察体」 | 红海边缘一条液体轨道波 |

#### 星球设计禁令

- 不做会眨眼卖萌的星球脸。
- 不做干净塑料球体贴「食物贴图」。
- 不在星球表面写可读菜名。

#### 新增扩展位（可选后续）

若需要第十一星，优先「家常但诡异」而非新奇炫技，例如：冻饺卫星群、油条环世界、皮冻暗海。仍服从同一混比。

### 3.3 怪物概念（Edible Anomalies）

怪物不是传统外星兽，而是「被宇宙误读的食物器官 + 官僚器械」。

设计公式：

`怪物 = 可识别食材组织 × 解剖错位 × 监视/测量部件 × 冷幽默行为`

#### 原型库

1. **取样舌（Probe Tongue）**  
   一条过长的酱汁舌头，末端是胶木把手或镜头盖。出现在意面星轨道，像在舔取样本。  
   玩家感受：恶心里带办公感。

2. **归档眼球（Filing Eye）**  
   写实眼球嵌在肉糜或凝胶里，虹膜有刻度环。不攻击，只「记录」。  
   玩家感受：被看见了。

3. **错版饺子（Misregistered Dumpling）**  
   饺子轮廓印糊了两层色边，壳能打开露出空白索引卡。  
   玩家感受：印刷错误活过来了。

4. **量尺蜈蚣（Caliper Centipede）**  
   身体是一节节金属卡尺，节间夹着菜叶或面条。沿假地平线爬行。  
   玩家感受：测量本身变成威胁。

5. **盐雾寄生体（Salt-Fog Host）**  
   从盐瓶喷出的雾凝成半透明小人形，手里仍像端着餐具。  
   玩家感受：餐桌礼仪在深空里失控。

6. **双影包子（Double-Exposure Bun）**  
   同一生煎叠两层半透明位移，咬合时两层对不齐。  
   玩家感受：现实拷贝坏了。

#### 怪物表现规则

- 动作慢、静、仪式感；少用狂暴冲刺。
- 受击反馈像纸面破损、网点剥落、错版加重，而不是血液喷泉特效。
- 死亡可变成「被归档」：吸入卡片格、盖上橡皮章轮廓、沉入目录洞。

### 3.4 美食概念（可采集 / 可交易 / 可烹饪）

美食在玩法上是资源，在美术上仍是「证物」。

| 品类 | 例子 | 视觉怎么画 | 玩家怎么读 |
|---|---|---|---|
| 地表收获 | 酱晶、叶脉片、焦壳碎 | 静物特写 + 小小刻度旁注块 | 这是从星球抠下的样本 |
| 轨道调料 | 帕玛森尘、芝麻陨、酸黄油膜 | 漂浮微粒带，轻微液体轨道 | 像环，也像佐料 |
| 合成冷盘 | 豆腐砖、醋冻块、归档午餐盒 | 方正、可堆叠、略错版边 | 像补给，也像档案 |
| 危险珍味 | 皮蛋核膏、双影馅 | 半透明 + 重复轮廓 | 好吃，但看着不对 |

表现要点：

- 图标也要有纸本质感与网点，不做应用商店贴纸风。
- 稀有度用「印刷异常」表达：错版越重、褐边越深、监视符号越多，越稀有。
- 堆叠数量可用打孔卡点或索引齿，而不是现代进度环。

### 3.5 UI 概念（界面也是封面系统）

CRT 小窗路线已验证失败：食物会变成终端控件。UI 必须改走「平装本封面操作系统」。

#### UI 总原则

- 界面像摊开的书页、索引卡、测量图板，不像飞船玻璃 HUD。
- 信息层级学封面：大空、中物、小注记。
- 海报感只出现在选中高光、危险脉冲、关键行动按钮的局部热色。
- 尽量少卡片；需要容器时用纸页区块、齿孔条、夹具线，而不是圆角阴影卡。

#### 关键界面概念

1. **星系图（Galaxy Spread）**  
   整页像打开的平装书中缝。星球落在负空间里；轨道是细线 + 少量液体波。选中星球时，旁侧弹出「索引条」而非弹窗。

2. **星球检视（Specimen View）**  
   中央是被观察的美食星；上方可有镜头/天线剪影；左侧竖尺，右侧文件齿。操作是「取样 / 建档 / 交易」，不是「攻击确认」。

3. **货摊/交易（Stall Ledger）**  
   像食堂记账页：品名用抽象色块标题条（避免大段可读伪文），数量是打孔，价格是印章圆。成交瞬间给一次氧化橙过印闪。

4. **遭遇战（Anomaly Contact）**  
   不是血条横幅乱飞。威胁用「观察进度」或「归档压力」表达：镜头光圈收紧、错版加重、纸边焦化。玩家行动按钮是厚油墨块，按下有丝网压印感。

5. **菜单/暂停（Title Cartouche）**  
   可用海报式外框丝带，但内部仍是大面积奶油纸负空间 + 一个不可能静物。品牌名必须是英雄级信号，不能被副标题压过。

#### UI 动效（至少 2–3 个有意图的运动）

1. **错版呼吸**：选中态色边轻微左右漂 1–2px，像印刷没套准。  
2. **镜头光圈**：进入星球时，监视圆环慢收，伴随网点变密。  
3. **液体轨道游走**：关键行动可用时，一条细酱汁轨道沿边缓行，不是闪烁粒子雨。

#### UI 文案与可读字

- 概念图默认无真实书名/作者/出版社。
- 游戏内必要文字用短、冷、目录语气：「样本」「在档」「不可食用？」「已观察」。
- 避免现代手游口吻：「领取！」「超值！」

### 3.6 构图菜谱（混合模式专用）

| 菜谱名 | 用法 | 混比操作 |
|---|---|---|
| `domestic-cosmos-heat` | 餐桌/灶台与虚空接缝，一颗食物星跨缝 | 平装本分割现实 + 一道液体轨道 |
| `specimen-under-lens` | 镜头下的单星特写 | 监视几何主导 + 局部酸黄高光 |
| `ledger-orbit` | 多星横陈如证物台 | 负空间与刻度主导 + 少量熔边丝带连星 |
| `stall-at-event-horizon` | 货摊台面伸进黑洞/虚空 | 家常器物锚定 + 海报热色只给招牌灯/酱瓶 |

## 4. 场景

以下场景用于指导概念图与后续原型，不写成系统说明书。

### 场景 A：第一次看见星系

玩家进入标题后，看到奶油色纸边上的褐渍，然后是一颗牛肉丸星停在盐瓶旁边，上方有一只冷静的镜头。没有欢呼音效，只有纸页展开感。玩家立刻明白：这宇宙好吃，但不安全。

### 场景 B：点开一卷心菜星

星球检视图里，叶层像被翻开的档案。右侧齿孔条列出「可收获：叶脉片」。玩家选择取样，画面出现轻微错版，像盖错了章。

### 场景 C：遭遇归档眼球

在醋冻星附近，眼球从凝胶里转过来。没有怒吼。观察环开始收紧。玩家选择「建档」或「逃离」。成功建档后，怪物被吸进卡片格，留下一枚闷红印章。

### 场景 D：货摊成交

玩家用帕玛森尘换焦壳碎。记账页盖下圆形章，氧化橙过印闪一下——这是全段唯一的「海报热」，随后立刻回到纸本冷静。

### 场景 E：危险珍味

玩家打开双影馅。图标显示两层对不齐的轮廓。食用后，短暂看到重复地平线。世界没有变可爱，只是更可疑。

## 5. 边界

### 5.1 混比边界（硬）

| 检查项 | 通过 | 失败 |
|---|---|---|
| 第一眼情绪 | 冷、被观察、旧书感 | 狂欢、可爱、电竞燃 |
| 色面积 | 奶油/褐黑/青绿占大场 | 酸黄橙绿满幅开花 |
| 构图 | 单一重心 + 负空间 | 曼陀罗贴纸墙 |
| 现实裂痕 | 至少 1 个 | 只有漂亮食物球 |
| 印刷 | 网点/错版/纸齿可见 | 光滑渲染 + 复古滤镜 |
| UI | 书页/索引/镜头 | CRT 窗、霓虹 HUD |

### 5.2 内容边界

- 可暗黑、可怪异，不做恶心猎奇冲脸和血腥夸张。
- 可荒诞，不做真实品牌、真实宗教符号、真实书籍复刻。
- 食物可「可疑不可食用」，但不宣扬真实世界有害饮食指导。

### 5.3 与旧资产关系

- `concepts/seventies-psychedelic-16x9.png`：海报端参考，取色与液体轨道，不取满幅放射统治。
- `concepts/paranoid-sci-fi-paperback-16x9.png`：主构图与气质参考，作为 70% 底座。
- `assets/food-planets/crt-*`：保留为历史试错；新方向默认不沿用 CRT 窗框与扫描线控件化。

### 5.4 明确不做

- NO FALLBACK 到「先用现代 UI 以后再换皮」。
- NO 静默把海报比例拉到 50% 以上。
- NO 为了可读性把菜名直接印星球上。

## 6. UAT

以下验收从玩家看见与操作出发，用 Cucumber 语言描述。实现方必须能对照这些句子判断美术是否合格。

```gherkin
Feature: 玩家能一眼读懂「可疑的可食用宇宙」
  作为一名新打开 Galaxy Food Stall 的玩家
  我想先被封面式的怪异宇宙抓住
  以便明白这是探索与交易美食星球，而不是太空射击或可爱养成

  Scenario: 标题第一屏的气质正确
    Given 我进入游戏标题画面
    When 我只看第一眼，不读任何说明
    Then 我应感到这是旧科幻平装书封面，而不是演唱会海报
    And 品牌名应是最醒目的文字信号
    And 画面里应有一处家常器物与宇宙尺度打架
    And 应能察觉有「被观察」的不安，而不是热闹欢迎

  Scenario: 美食星球可识别且保持怪异
    Given 我打开星系图并点选「生煎包星」
    When 星球进入检视
    Then 我应立刻认出它是生煎包，而不是普通岩石球
    And 我也应承认它是一颗行星，有暗面、尺度与轨道关系
```
