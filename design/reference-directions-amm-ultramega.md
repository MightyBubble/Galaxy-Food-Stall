# 参考方向方案：绝对火星猎人 / Ultramega

## 1. 概述

本文件给 `Galaxy Food Stall` 增加两套**封面级**视觉参考方向，来源是两部当代漫画的视觉语言，而不是复刻某一张现成封面：

| 代号 | 参考源 | 一句话气质 |
|---|---|---|
| **方向 A · 情绪烟色** | 《绝对火星猎人》Absolute Martian Manhunter（Deniz Camp / Javier Rodríguez） | 日常世界发灰，外星意识用有限高饱和色与烟状色流破开现实 |
| **方向 B · 黑光宇宙巨物** | 《Ultramega》封面语言（James Harren / Dave Stewart） | 深黑宇宙底 + 品红/电青霓虹对比 + 巨物尺度压迫 + 颗粒飞溅星云 |

它们不是取代现有主指南 `art-bible-hybrid-70-30.md`，而是两套**可并行试拍**的封面参考轨：

- 若继续走「旧书证物台」：仍以 hybrid 70/30 为主。
- 若想更「当代漫画封面冲击力」：用本文件两套方向做 A/B 试片，再决定是否回灌主圣经。

硬规则：只借构图、色温对比、符号语法与印刷/油墨感；**不抄角色外形、标志、标题字、具体封面构图、具体分镜。**

| 叙事幽默 | 冷、心理、被入侵的头脑 | 宇宙级荒诞：巨人把星球当点心捏 |
| 最适合做 | 标题屏、遭遇「被观察」、珍味幻觉 | 标题主视觉、星系图英雄帧、巨物事件 |

## 3. 详情

### 3.1 方向 A · 情绪烟色（Absolute Martian Manhunter 参考）

#### 参考源里真正值钱的封面语法

来自公开访谈与封面阅读，可借的是**系统**，不是某个英雄立绘：

1. **灰/闷日常 vs 有限高饱和「他者色」**  
   主角职场世界偏闷；外星意识出现时，一套很短的色表统治画面，甚至带一点迷幻，但不是彩虹乱泼。
2. **色即信息**  
   颜色不只是好看，而是情绪/感知外溢。烟、雾、色带从口鼻、缝隙、切面涌出。
3. **极简可识别形（Pareidolia）**  
   一个能印在文化衫上的剪影：插座像脸、钥匙孔像眼睛、单眼像灯塔。形状怪，但一眼能记住。
4. **二维图形优先**  
   清晰线 + 平涂色块 + 60 年代 mod / 轻波普感觉；雕塑感只服务设计，最终画面仍偏平面图形。
5. **封面构图常是「入侵式」**  
   不是英雄摆拍，而是彩色他者渗入灰房间、灰街道、灰面孔。

#### 落到 Galaxy Food Stall

| 对象 | 怎么借 |
|---|---|
| **星球** | 星球本体可用闷纸色/官僚青塑造；「可食用异常」用 5–7 色烟带从裂缝涌出。例：皮蛋星核裂开，绿-洋红-酸黄烟流像被读心。 |
| **怪物** | 少做肌肉兽，多做「可识别抽象器官」：单眼酱团、钥匙孔状生煎褶、插座脸豆腐砖。威胁是渗入与改色，不是追咬。 |
| **美食** | 珍味打开时，颜色从包装/切口喷出情绪烟；普通补给保持闷色。稀有度 = 烟色种类与纯度。 |
| **UI** | 常态界面接近灰档案；选中/危险/精神污染时，色烟漫过分隔线。按钮是平涂色块，不是玻璃霓虹。 |

#### 封面试片配方（方向 A）

- **主画面**：一间发灰的食堂后厨或调查局式桌面；中央一颗闷色食物星。
- **入侵**：从星球气孔喷出有限色烟（绿 / 红 / 蓝 / 黄为主，另加 1–2 变体）。
- **符号**：一个单眼或钥匙孔形监视点藏在烟里。
- **文字位**：上或下留大负空间给品牌名（试片可留空块，不写真书名）。
- **完成感**：像当代另类超英封面，而不是 70 年代平装书扫描件。

#### 色板建议（方向 A）

| 角色 | 用途 |
|---|---|
| 职场灰、闷青绿、烟灰 | 日常底 |
| 火星绿、信号红、电蓝、酸黄、洋红 | 他者色烟（同时出场 ≤6） |
| 纯白慎用 | 留给「彻底异质」的稀有实体，勿当背景 |

#### 与 hybrid 70/30 的关系

- **可兼容**：监视、现实裂痕、冷幽默。
- **会拉开**：印刷旧书感下降，当代漫画平涂与情绪色烟上升；迷幻海报的液体轨道可改成「思想色烟」。
- **别混成**：既要旧纸褐边又要荧光烟海——选一边做主。

### 3.2 方向 B · 黑光宇宙巨物（Ultramega **封面**参考）

> 纠偏：方向 B 对齐的是 Ultramega **封面海报语言**（深黑底、品红/电青霓虹、颗粒星云飞溅、巨物捏星球），**不是**内页里那种汤绿湿城、内脏喷泉写实恐怖。旧试片 `ref-dir-B-ruin-kaiju-cover-16x9.png` 视为错轨，以本节约定为准。

#### 参考源里真正值钱的封面语法

从用户给出的封面类型抽象出来（宇宙捏星球型 / 黑光压城型）：

1. **深黑底是主角**  
   虚空不是灰雾，是浓黑；星点与品红/紫红飞溅星云像油漆甩在纸上。
2. **极窄霓虹色对**  
   主对撞几乎只有：**品红/洋红 ↔ 电青/天蓝**，再点缀酸绿、热粉、条纹蓝等「假行星色」。像黑光海报，不是自然星空。
3. **巨物剪影 + 平面高饱和填色**  
   巨人可用单一高饱和色块（如平涂蓝）或裂纹透光剪影；粗野墨线、颗粒、点刻阴影，不做光滑 3D。
4. **尺度笑话写在封面上**  
   巨手捏住一颗「小」星球；或巨影压住底层城市/小身影。压迫感来自比例，不是血迹特写。
5. **星球是概念球，不是真实 NASA**  
   整颗是密林球、条纹气态球、多孔粉月、单树小岛——换成美食就是：整颗卷心菜球、条纹果冻球、多孔芝士月。
6. **底部可留干净色带给标题**  
   手绘粗锯齿字、红青对撞或品红-电青渐变字感；试片可留白带，不写真商标。

#### 落到 Galaxy Food Stall

| 对象 | 怎么借 |
|---|---|
| **星球** | 概念美食球漂在黑光宇宙：酸绿卷心菜密林球、热粉芝士多孔月、条纹醋冻气态球、焦橙肉丸小卫星。 |
| **怪物/巨物** | 平涂高饱和的「食堂巨人」或裂纹透光巨影；可捏、可抓、可俯视美食星。不抄任何特摄英雄头冠/胸灯造型。 |
| **美食** | 被巨手捏住的星球本身就是菜；碎屑卫星是芝麻/花椒/叶瓣。 |
| **UI** | 黑底 + 品红/电青双色系统；标题字用手绘粗边；选中态像星云飞溅，不是玻璃扫光。 |

#### 两种封面菜谱（方向 B）

**B1 · 宇宙捏星球（偏 #8 类封面）**

- 浓黑宇宙 + 品红/紫飞溅星云。
- 一尊高饱和平涂巨人（原创食堂巨像）斜向占画。
- 巨手抓住/护住一颗可读美食星（如卷心菜密林球或生煎包星）。
- 周围再散 2–4 颗概念美食星（粉芝士月、条纹冻星等）。
- 底部可留白/色带给字。

**B2 · 黑光压城（偏 #1 类封面）**

- 巨物几乎满幅剪影，裂纹透出品红/电青光。
- 底边是密细城市或食堂街区剪影；正中一丁点小人/小摊定尺度。
- 色板锁死：黑 + 品红 + 电青，几乎不引入第三主色。
- 完成感：黑光摇滚海报遇上宇宙巨物，不是写实灾难片。

#### 色板建议（方向 B）

| 角色 | 用途 |
|---|---|
| 浓黑 `#0A0A0C` | 虚空主底 |
| 品红/洋红 `#FF2D7A`–`#E81B5E` | 星云飞溅、字、巨物描边光 |
| 电青/天蓝 `#2DE2E2`–`#3AA7FF` | 巨人填色或第二霓虹 |
| 酸绿 `#7CFF3A` | 概念森林/菜星球点缀 |
| 热粉、条纹蓝、焦橙 | 背景小星球，各用一点 |

#### 与 hybrid 70/30 的关系

- **可兼容**：宇宙尺度荒诞、颗粒印刷感、非写实星球。
- **会拉开**：奶油纸本与官僚青退场；黑光霓虹与巨物海报感上台。
- **别混成**：不要在尼古丁奶油纸页上硬贴品红电青黑光——封面只能选一个主场。

### 3.3 两套方向对照（决策用）

| 问题 | 选 A 情绪烟色 | 选 B 黑光宇宙巨物 |
|---|---|---|
| 玩家第一情感 | 「我的感官被改写了」 | 「有巨人在深空里捏我的菜星球」 |
| 最佳系统表达 | 观察、建档、精神污染、珍味幻觉 | 标题主视觉、星系英雄帧、巨物事件 |
| 标题屏 | 灰厨房被色烟切开 | 黑宇宙里巨手捏美食星 / 黑光巨影压城 |
| 风险 | 太抽象导致认不出是美食游戏 | 太像泛特摄超英，丢了「食堂宇宙」 |
| 与现有概念图 | 更靠近「归档眼球」的被注视感 | 更靠近「可食用星系」的冲击海报 |

### 3.4 禁止项（两套共用）

- 不复制两部作品的角色、标志、标题字样、具体封面姿势（含特摄头冠、胸灯菱形等可识别符号）。
- 不做美式超英摆拍肌肉海报当唯一语言。
- 不把 A 的荧光烟做成全幅扎染；不把 B 做成电竞玻璃 HUD 或写实汤绿内脏恐怖（那是错轨）。
- 美食识别不能丢：再霓虹、再巨物，也要先让人认出「这是菜」。

## 4. 场景

### 场景 A1（情绪烟色 · 标题）

玩家看见一间发灰的深夜食堂。灶台上有一颗安静的生煎包星。突然从褶缝喷出绿与洋红的烟，烟里浮出一只钥匙孔形的单眼。品牌名压在烟上方的负空间。玩家感到：这宇宙会进到脑子里。

### 场景 A2（情绪烟色 · 珍味）

玩家打开皮蛋核膏。界面底色发闷，切口喷出色烟，短暂改写周围图标颜色。没有爆炸，只有「世界被重新上色」。

### 场景 B1（黑光宇宙巨物 · 宇宙捏星球标题）

浓黑天上甩着品红星云点。一尊平涂电青的食堂巨人斜浮着，双手小心又粗鲁地捏住一颗酸绿卷心菜星球。旁边漂着热粉芝士月和条纹醋冻星。底部留一条干净色带给游戏名。玩家感到：星系是被巨物当零食摆弄的。

### 场景 B2（黑光宇宙巨物 · 黑光压城）

裂纹巨影占满画面，品红与电青从缝里漏光。底边密密的食堂街与小摊剪影，正中一个点大的人影抬头。没有血雾，只有比例带来的压迫。玩家感到：今晚的摊，开在巨人脚边。

## 5. 边界

1. 本文件是**参考方向**，不是立即替换 `art-bible-hybrid-70-30.md` 的生产 SSOT。  
2. 试片阶段允许各出封面级概念图；定主风格前不得把三套语言无进同一张生产资产。  
3. 方向 B 的压迫来自尺度与霓虹对比；不做写实内脏冲脸，也不滑向电竞 UI。  
4. 方向 A 的抽象止于「仍能认出食物」；不做纯几何装饰画。  
5. NO FALLBACK：若试片失败，明确记录失败原因，不静默混回旧 CRT 或纯海报。
