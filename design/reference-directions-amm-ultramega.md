# 参考方向方案：绝对火星猎人 / Ultramega

## 1. 概述

本文件给 `Galaxy Food Stall` 增加两套**封面级**视觉参考方向，来源是两部当代漫画的视觉语言，而不是复刻某一张现成封面：

| 代号 | 参考源 | 一句话气质 |
|---|---|---|
| **方向 A · 情绪烟色** | 《绝对火星猎人》Absolute Martian Manhunter（Deniz Camp / Javier Rodríguez） | 日常世界发灰，外星意识用有限高饱和色与烟状色流破开现实 |
| **方向 B · 残骸巨物** | 《Ultramega》（James Harren / Dave Stewart） | 城市与人物又脏又累，食物巨物冲进画面时才炸出刺眼色块 |

它们不是取代现有主指南 `art-bible-hybrid-70-30.md`，而是两套**可并行试拍**的封面参考轨：

- 若继续走「旧书证物台」：仍以 hybrid 70/30 为主。
- 若想更「当代漫画封面冲击力」：用本文件两套方向做 A/B 试片，再决定是否回灌主圣经。

硬规则：只借构图、色温对比、符号语法与印刷/油墨感；**不抄角色外形、标志、标题字、具体封面构图、具体分镜。**

| 封面第一眼 | 灰日常被彩色外星意识切开 | 巨物压迫 + 脏灰底上的爆色 |

| 最适合做 | 标题屏、遭遇「被观察」、珍味幻觉 | 遭遇战、巨型怪物、星球地表灾难 |

## 3. 详情

### 3.1 方向 A · 情绪烟色（Absolute Martian Manhunter 参考）

#### 参考源里真正值钱的封面语法

来自公开访谈与封面阅读，可借的是**系统**，不是某个英雄立绘：

1. **灰/闷日常 vs 有限高饱和「他者色」**  
   主角职场世界偏闷；外星意识出现时，一套很短的色表统治画面，甚至带一点迷幻，但不是彩虹乱泼。
2. **色即信息**  
   颜色不只是好看，而是情绪/感知外溢。烟、雾、色带从口鼻、缝隙、切面涌出。
3. **极简可识别形（Pareidolia）**  
   一个能印在文化衫上的剪影：插座像脸、钥匙孔像眼睛、单眼像灯塔。形状怪，但一眼能记住。
4. **二维图形优先**  
   清晰线 + 平涂色块 + 60 年代 mod / 轻波普感觉；雕塑感只服务设计，最终画面仍偏平面图形。
5. **封面构图常是「入侵式」**  
   不是英雄摆拍，而是彩色他者渗入灰房间、灰街道、灰面孔。

#### 落到 Galaxy Food Stall

| 对象 | 怎么借 |
|---|---|
| **星球** | 星球本体可用闷纸色/官僚青塑造；「可食用异常」用 5–7 色烟带从裂缝涌出。例：皮蛋星核裂开，绿-洋红-酸黄烟流像被读心。 |
| **怪物** | 少做肌肉兽，多做「可识别抽象器官」：单眼酱团、钥匙孔状生煎褶、插座脸豆腐砖。威胁是渗入与改色，不是追咬。 |
| **美食** | 珍味打开时，颜色从包装/切口喷出情绪烟；普通补给保持闷色。稀有度 = 烟色种类与纯度。 |
| **UI** | 常态界面接近灰档案；选中/危险/精神污染时，色烟漫过分隔线。按钮是平涂色块，不是玻璃霓虹。 |

#### 封面试片配方（方向 A）

- **主画面**：一间发灰的食堂后厨或调查局式桌面；中央一颗闷色食物星。
- **入侵**：从星球气孔喷出有限色烟（绿 / 红 / 蓝 / 黄为主，另加 1–2 变体）。
- **符号**：一个单眼或钥匙孔形监视点藏在烟里。
- **文字位**：上或下留大负空间给品牌名（试片可留空块，不写真书名）。
- **完成感**：像当代另类超英封面，而不是 70 年代平装书扫描件。

#### 色板建议（方向 A）

| 角色 | 用途 |
|---|---|
| 职场灰、闷青绿、烟灰 | 日常底 |
| 火星绿、信号红、电蓝、酸黄、洋红 | 他者色烟（同时出场 ≤6） |
| 纯白慎用 | 留给「彻底异质」的稀有实体，勿当背景 |

#### 与 hybrid 70/30 的关系

- **可兼容**：监视、现实裂痕、冷幽默。
- **会拉开**：印刷旧书感下降，当代漫画平涂与情绪色烟上升；迷幻海报的液体轨道可改成「思想色烟」。
- **别混成**：既要旧纸褐边又要荧光烟海——选一边做主。

### 3.2 方向 B · 残骸巨物（Ultramega 参考）

#### 参考源里真正值钱的封面语法

1. **脏、累、湿的世界底**  
   城市与人像泡在汤绿、褐灰、病黄里；生活本身已经很糟。
2. **巨物一进场，颜色与形同时爆炸**  
   灰底上突然砸进实心红、毒绿、脏紫、灼橙；像暴力波普，不是梦幻迷幻。
3. **合成畸形可读**  
   昆虫壳 + 哺乳肉 + 触须组织拼成墙；恐怖在于「明明认出零件却拼错了」。
4. **封面常是对峙与压迫**  
   英雄/观者极小或被挤到边；怪物墙、碎城、内脏烟柱占主面积。
5. **民间涂鸦 × 粗野线**  
   能量感像墙绘和民间画的硬边，不是细腻空气透视。动作封面可有速度线，但仍服务巨物重量。

#### 落到 Galaxy Food Stall

| 对象 | 怎么借 |
|---|---|
| **星球** | 星球可以是「已经咬崩的食堂世界」：意面大陆塌陷、酱海喷柱、芝士坑像弹坑。地貌要有灾难后的脏与重。 |
| **怪物** | 美食 kaiju：卷心菜甲壳蜈蚣、炸壳甲胄肉丸、面条触须墙。零件都是食材，拼法是错的。 |
| **美食** | 战利品像从巨物身上撕下的组织块：还在抖的叶脉片、冒热气的酱核。好看但不安心。 |
| **UI** | 底界面脏灰；警报与开战才爆色。进度像城市损毁条，不是可爱经验条。少玻璃 HUD，多厚油墨块与破碎边。 |

#### 封面试片配方（方向 B）

- **主画面**：一颗食物巨物（或巨物墙）占画面 60%+，俯压货摊或小小玩家剪影。
- **环境**：碎掉的食堂街道 / 塌了一半的摊位棚，汤绿色雾。
- **爆色**：只有巨物伤口、酱喷、能量带用高饱和；其余保持病灰。
- **完成感**：像特摄恐怖超英封面，而不是可爱美食星球明信片。

#### 色板建议（方向 B）

| 角色 | 用途 |
|---|---|
| 汤绿、褐灰、湿水泥、病黄 | 世界底 |
| 血橙红、毒叶绿、脏紫、灼橙 | 巨物/开战爆点 |
| 少量电青 | 英雄或「反击瞬间」点睛，勿铺满 |

#### 与 hybrid 70/30 的关系

- **可兼容**：冷幽默可升级为「灾难后的干笑」；食物仍是可读地貌。
- **会拉开**：平装本负空间与静物感下降；冲击力、体量、组织恐怖上升。
- **别混成**：一边档案馆静物，一边内脏喷泉——封面只能选一个主事件。

### 3.3 两套方向对照（决策用）

| 问题 | 选 A 情绪烟色 | 选 B 残骸巨物 |
|---|---|---|
| 玩家第一情感 | 「我的感官被改写了」 | 「有东西要踩扁我的摊子」 |
| 最佳系统表达 | 观察、建档、精神污染、珍味幻觉 | 遭遇战、巨物事件、地表开采风险 |
| 标题屏 | 灰厨房被色烟切开 | 巨物阴影罩住小货摊 |
| 风险 | 太抽象导致认不出是美食游戏 | 太暴力血腥盖过「美食宇宙」卖点 |
| 与现有概念图 | 更靠近「归档眼球」的被注视感 | 更靠近「灾难化星球」与怪物墙 |

### 3.4 禁止项（两套共用）

- 不复制两部作品的角色、标志、标题字样、具体封面姿势。
- 不做美式超英肌肉英雄摆拍当主视觉。
- 不把 A 的荧光烟做成全幅扎染；不把 B 的爆色做成电竞霓虹 HUD。
- 美食识别不能丢：再抽象/再畸形，也要先让人认出「这是菜」。

## 4. 场景

### 场景 A1（情绪烟色 · 标题）

玩家看见一间发灰的深夜食堂。灶台上有一颗安静的生煎包星。突然从褶缝喷出绿与洋红的烟，烟里浮出一只钥匙孔形的单眼。品牌名压在烟上方的负空间。玩家感到：这宇宙会进到脑子里。

### 场景 A2（情绪烟色 · 珍味）

玩家打开皮蛋核膏。界面底色发闷，切口喷出色烟，短暂改写周围图标颜色。没有爆炸，只有「世界被重新上色」。

### 场景 B1（残骸巨物 · 标题）

玩家的小货摊只占画面一角。上方是一堵由卷心菜甲、面条触须、肉丸关节拼成的巨物墙，伤口喷着灼橙酱。天空是汤绿色。玩家感到：先活过今晚，再谈买卖。

### 场景 B2（残骸巨物 · 遭遇）

意面星地表塌陷，触须墙立起。开战瞬间，脏灰界面被实心红与毒绿切开。胜利后留下还在颤的帕玛森尘与焦壳碎——像战利品，也像组织样本。

## 5. 边界

1. 本文件是**参考方向**，不是立即替换 `art-bible-hybrid-70-30.md` 的生产 SSOT。  
2. 试片阶段允许各出封面级概念图；定主风格前不得把三套语言无进同一张生产资产。  
3. 方向 B 的恐怖止于「错拼食材巨物」；不做过度写实血腥冲脸。  
4. 方向 A 的抽象止于「仍能认出食物」；不做纯几何装饰画。  
5. NO FALLBACK：若试片失败，明确记录失败原因，不静默混回旧 CRT 或纯海报。

## 6. UAT

```gherkin
Feature: 两套漫画封面参考方向能被玩家区分，且仍像 Galaxy Food Stall
  作为美术与玩法共同决策者
  我想用玩家第一眼就能分清的两套封面试片
  以便决定标题与遭遇的主视觉轨道

  Scenario: 方向 A 读作「感官被改写」而不是「旧书静物」
    Given 我只看方向 A 的标题概念图 3 秒
    When 我不看任何说明文字
    Then 我应感到日常底色发闷，且有有限高饱和色烟入侵
    And 我应能认出至少一个美食星球或食材形
    And 我不应觉得这是 70 年代平装书扫描件
    And 我不应认出任何《绝对火星猎人》的具体角色外形

  Scenario: 方向 B 读作「巨物要碾摊」而不是「可爱美食曼陀罗」
    Given 我只看方向 B 的标题概念图 3 秒
    When 我不看任何说明文字
    Then 我应感到尺度压迫与脏灰世界底
    And 巨物零件应能被认成食材，即使拼法是错的
    And 高饱和色应集中在伤口/喷发/开战，而不是铺满背景
    And 我不应认出任何 Ultramega 的具体英雄或怪物设计

  Scenario: 两套方向不会互相冒充
    Given 方向 A 与方向 B 的试片并排
    When 我比较第一眼情绪
    Then A 应更偏「被渗入/被改色」
    And B 应更偏「被碾压/要开战」
    And 两者都应仍能被描述为「可食用却可疑的宇宙」
```
