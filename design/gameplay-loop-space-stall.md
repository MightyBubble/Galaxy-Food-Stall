# 银河大排档：玩法循环（潜水员戴夫 × 超光速航线，发生在可食用宇宙）

## 1. 概述

玩家开的不是星际帝国，而是一艘又当货船、又当夜市摊的「航线食堂船」。

每天两截生活，和潜水员戴夫同构，但空间换成宇宙分层：

- **当班下潜**：从轨道跳进行星大气、低重力表面、再往食物地壳深处走一遭，把当天的食材带回来。
- **开摊营业**：夜里把今天采到的可疑美食做成菜单，服务过路船员、官僚、以及不愿具名的观察者。

超光速航线那一套，不做成全程战争，而做成「下一班要停哪颗星」的压力：燃料、航线风险、偶遇、以及「这颗星今晚值不值得下去」。

一句话：

> 白天你是去星球里进货的人；夜里你是把进货做成热食的人；航线决定你明天能进哪家货。

## 3. 详情

### 3.1 一日循环（核心）

**上午班 · 下潜一次**  
选一颗停靠星，穿上装具，从船边「落下去」。限制不是血条狂欢，而是三样硬东西：

1. **回升窗**：大气窗口会关。超时要弃货弹射，或烧掉额外燃料强行回船。
2. **货舱重量**：采得越多越沉，低重力区还好走，进入深处或回升时会拖垮你。
3. **观察压**：被镜头、归档眼球、行星自己「看见」会升高。满了不是直接死亡，而是今天的货会被标成「不可食用？」——夜里卖得出去，但口碑发虚。

**下午班 · 可再下一趟或改做船上事务**  
补今天菜单缺的那一味，或修冷柜、研究菜谱、打发船员。

**夜班 · 开摊**  
菜单只能用船上现有存货。客人按航线类型来：货船队爱重口，官僚爱「已建档」的干净样本，深空旅人爱危险珍味。你端盘、补酱、收桌、处理特殊单。

赚到的钱不是去买激光炮，而是：

- 更好的下潜装具（更深、更久、货舱更大）
- 更好的冷藏与摊位（同时接待更多过路船）
- 航线燃料与跃迁校准（明天能去更远的星）

### 3.2 空间分层（取代「海的深度」）

每一颗美食星都有同一套垂直语言，地貌不同：

| 层 | 玩家身体感觉 | 能采到什么 | 典型麻烦 |
|---|---|---|---|
| **宇宙 / 轨道环** | 船外慢漂，几乎无重力 | 环尘调料、废弃货箱、轨道冻饺 | 跃迁残骸、监视卫星、燃料泄漏 |
| **大气层** | 有阻力的滑翔 / 坠落控制 | 风暴里的油膜、飞着的葱花群、酸雨凝胶 | 酱暴、能见度差、窗口关闭 |
| **低重力表面** | 跳得高、刹不住、货物会飘 | 地表叶脉、焦壳、芝士孔里的凝脂 | 尺度错觉、巨大餐具、缓慢滚落 |
| **地壳深处** | 更沉、更热、更像被吞进去 | 核膏、双影馅、稀有剖面 | 归档眼球、错版生物、回升距离长 |

深度不是「打得更疼」，而是「回得更贵」：采到好东西，要算得清能不能在窗口关上前拖回船上。

### 3.3 超光速航线怎么接进来（不做成第二款战争游戏）

航线图是「今晚过后去哪」的决策，不是银河征服。

- **燃料**：下潜和跃迁都烧。燃料本身也是一种「宇宙调料」，有的星轨上能刮到，有的要拿夜摊收入买。
- **航线事件**（短、怪、可绕）：盘查、抛锚船要吃的、错版空间、免费但会抬高观察压的捷径。
- **停靠承诺**：有的客人会提前点「下一颗番茄酱星的红海」。你要决定是改航去兑现，还是今晚用存货糊弄然后掉口碑。
- **船是据点**：冷柜、摊位、船员铺、跃迁芯、观察档案柜。损坏会让夜班或下潜变差，而不是弹出一堆炮台小游戏。

战斗可以有，但是遭遇里的一种，不是主循环。主循环永远是：进货 → 做菜 → 走航线。

### 3.4 玩法点子（可做、且服务同一循环）

1. **菜单驱动下潜**  
   夜班开始前先看「今晚可能来的船」。你不是无脑扫荡，而是潜下去找缺的那一味。

2. **活体冷藏 vs 建档冷藏**  
   有的食材必须活着带回（会占货舱、会动）；有的可以现场切片建档（轻，但失去「刚捞上来」的溢价）。

3. **窗口天气**  
   番茄酱星大气是红风暴，卷心菜星是叶幕潮汐。同一颗星不同班次，可走层不一样。

4. **低重力搬运谜题**  
   一块巨大焦壳在低重力里能当盾、当跳板、也会砸摊。采集带一点「搬家具」。

5. **观察压做软失败**  
   被看见太多，夜班会出现戴镜头的客人，只点「样本」不点热食，钱少但推进故事。

6. **船员即班组**  
   有人留守摊、有人跟你下潜、有人盯航线。不是收集超人，是排班。

7. **禁菜与流言**  
   某颗星的核膏好吃，但航线法令标了「暂不可食用」。卖不卖是口碑赌局。

8. **回航剪影**  
   满载回升穿过大气时，货物会在窗口里被风刮掉一层——你要决定丢掉哪一袋保命。

### 3.5 一颗星怎么玩（例：番茄酱星）

- 轨道：油膜环，可刮「轨道调料」。
- 大气：红风暴，能见度低，适合抓气泡岛。
- 低重力表面：黏稠，跳不高，适合稳采。
- 深处：永久风暴眼，观察压极高，出危险珍味。

夜班用红海货做重口菜单，货船队会排队；官僚会皱眉。

## 4. 场景

### 场景 A：第一天学会循环

玩家从食堂船醒来。航线图上最近一颗是生煎包星。跳过去，从轨道落到低重力褶皱山脉，采了芝麻陨和焦底壳，窗口提示还剩三分之一。回船后打开夜摊，过路船员点「焦底拼盘」。卖完，钱只够修冷柜一格。玩家明白：下去是为了今晚，今晚是为了明天能潜更深。

### 场景 B：菜单缺一味

夜班预告有官僚船。菜单缺「已建档的叶脉片」。玩家放弃再刷牛肉丸星，改航去卷心菜星，只在表面翻开一层叶片就走。夜班官僚给了稳妥好评，没有爆款，但观察压没升。

### 场景 C：深处贪心

玩家在皮蛋星核区挖到核膏，货舱超重。回升时大气窗口关闭。玩家丢掉一半焦壳才弹回船上。核膏夜里卖了高价，但有客人吃完看见了重复地平线。口碑裂开。

### 场景 D：航线捷径

地图上有条「免费跃迁」，路过一只归档眼球。玩家走了。燃料省了，观察压拉满。当晚客人全是来建档的，热食几乎没人点。玩家学会：便宜航线会改写夜班客群。

### 场景 E：低重力搬家

炸薯球星表面，一块金壳比人还大。玩家把它当跳板蹦到油光裂谷，采到稀有日珥焦斑。金壳自己慢慢飘走，差点砸到回升绳。紧张，但不靠开枪解决。

## 5. 边界

1. 主循环必须能一句话说清：下潜进货 → 开摊卖出 → 走航线换下一颗星。  
2. 宇宙分层是「深度」，不是四个互不相干的小游戏拼盘。  
3. 超光速航线服务停靠与风险，不升级成银河战争模拟。  
4. 失败优先「丢掉货物 / 错过窗口 / 口碑发虚」，少用突然死亡。  
5. 食物始终可识别：采的是地貌，不是随机宝石。  
6. 美术仍走平装本；玩法概念图同样遵守，不做霓虹射击 HUD。  
7. NO FALLBACK 把夜摊做成无意义自动收钱，或把下潜做成无限制逛街。

## 6. UAT

```gherkin
Feature: 玩家能靠一天两截生活读懂银河大排档
  作为一名新开航线食堂船的摊主
  我想白天去可食用星球进货，夜里把货做成热食
  以便靠口碑和燃料把船开向下一个可疑的世界

  Scenario: 第一天就能感到循环合上
    Given 我停在一颗生煎包星轨道
    When 我完成一次下潜并连着开完夜摊
    Then 我应能指出今晚桌上的菜来自这次下去采到的东西
    And 我应看到赚到的钱可以花在装具、冷柜或燃料上
    And 我不需要先打赢一场宇宙战争才能开摊

  Scenario: 空间分层像「越走越深」而不是四个杂项模式
    Given 我从轨道进入同一颗星
    When 我依次穿过大气、低重力表面、再往深处走
    Then 每一层都应还是这颗星的食物地貌，只是更难回升
    And 我应感到货越沉、窗口越紧，而不是突然换成别的玩法

  Scenario: 航线选择会改写今晚的客人
    Given 我可以选稳妥航线或一条会抬高观察压的捷径
    When 我走捷径抵达
    Then 当晚客人构成应明显不同
    And 我应能把这个结果归因于航线，而不是随机惩罚

  Scenario: 贪心有代价但不粗暴
    Given 我在深处挖到了很贵的核膏且货舱过重
    When 回升窗口即将关闭
    Then 我应能选择弃货求生或冒险强行回船
    And 即使成功，夜班也可能因「可疑食材」出现怪异客人

  Scenario: 低重力表面有自己的身体感觉
    Given 我站在炸薯球星的硬壳上
    When 我跳跃或推动一块大金壳
    Then 我应感到人轻、货会飘、刹不住
    And 这个麻烦应靠搬运和时机解决，而不是靠一排枪械按钮
```
