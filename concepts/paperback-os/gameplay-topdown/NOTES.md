# Paperback OS — Top-Down Gameplay Maps

Paranoid Sci-Fi Paperback primary (nicotine cream / brown-black / faded teal; matte airbrush; paper grain; halftone; misregister). Psychedelic wavy ornaments **corners only**. No CRT, no neon glass cockpit, no readable logos. Abstract glyphs OK.

**Camera lock:** 2D overhead / slight 3/4 top-down like Zelda / Stardew / FTL. Player is a small sprite seen from above. These plates replace cinematic side-view readings of the same layers. Depth is chosen by walking into a hatch/ring, or by picking a concentric ring — never by a side-view dive.

## Gate reminders

- Must read as a **2D top-down game screenshot**, not a movie still or side-view dive.
- No readable English/Chinese labels on crates, cans, or pouches.
- Atmospheric window / exit shaft is a physical printed ring tile, not cockpit glass.
- Psychedelic heat stays in corner ornaments (plus one liquid band if needed).
