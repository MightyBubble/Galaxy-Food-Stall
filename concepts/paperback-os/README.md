# Paperback OS Concept Batch

Primary production look: **Paranoid Sci-Fi Paperback**, with psychedelic energy reserved for **UI corners / frame ornaments**.

## Style lock

- Flat graphic screens, printed on nicotine paper (halftone, matte ink, slight misregister)
- Not CRT, not glass neon HUD, not mobile-app chrome
- Corner frames: wavy liquid ribbons / scalloped cartouches (burnt orange, acid yellow, avocado, deep violet)
- Food planets should feel planetary (terminator, atmosphere, limb darkening) while staying food-readable
- Roster only: beef ball, shengjianbao, pasta, cheese, tofu, century egg, fried potato ball, cabbage, vinegar jelly, ketchup
